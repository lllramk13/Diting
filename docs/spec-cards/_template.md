# 规格卡：<页面名>

- 路由：`<path>`
- 权限：`[公开]` / `[登录]` / `[成员]` / `[审核]` / `[管理]`
- 批次：第 N 批

## 1. 给谁看

按优先级列出这页服务的用户类型，以及每种人来这页的目的。

## 2. 从哪进，往哪出

进入路径（谁会链到这页）；页面上每个区块指向的出口。一个区块没有出口要能说出理由。

## 3. 核心数据

这页要展示什么数据、来自哪些表/RPC。写完对照 er.md 和权限矩阵检查：查得出来吗？该角色查得到吗？

## 4. 主要操作

用户在这页能做什么（读/写分开列）。写操作标注权限与登录要求。

## 5. 空态

数据为空时长什么样（新项目、零任务、零发布……）。空态要给出下一步引导，不是一句"暂无数据"。

## 6. 无权限态

未登录 / 无权限的人打开这页看到什么：跳登录（带 returnTo）？看降级版本？404？
