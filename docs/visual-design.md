# Visual Design

状态：骨架。设计系统阶段填充（见 roadmap，位于线框之后）。

职责：设计系统、视觉模式、交互与响应式规范的真源。

## 待写章节

1. **设计原则**：复古科幻终端气质 × 现代可用性；观赏模式只能增加气氛，不能降低可用性。
2. **实用模式 / 观赏模式**：两种模式的实现边界，对照 README「视觉原则」——相同的信息结构、按钮位置和操作逻辑。
3. **Design Tokens**：颜色、字体、字号、间距、圆角、辉光与扫描线参数；两种模式共享一套 token，观赏模式只叠加效果层。
4. **核心组件规范**：按钮、输入、表格、状态标签、进度、弹窗、Toast。
5. **响应式断点与移动端行为**：导航抽屉、编辑器在窄屏下的布局。
6. **可访问性**：对比度底线、键盘操作、焦点样式、`prefers-reduced-motion`。
